INFORMAÇÕES RELVANTES AO PORTIFOLIO
	Sou Analista de Automação RPA na MV3 Tecnologia e estudante de Engenharia de Software na FIAP, com foco no desenvolvimento de soluções que unem programação, automação de processos e integração de sistemas.

	Tenho experiência com Python, SQL, APIs REST, web scraping e ferramentas de RPA, desenvolvendo soluções para automatizar processos, integrar sistemas e otimizar operações. Também possuo conhecimentos em desenvolvimento backend, desenvolvimento web, bancos de dados e inteligência artificial, aplicando esses conhecimentos em projetos profissionais e pessoais.

	### 1. News Scraper API
	**Resumo:** API desenvolvida para coletar, armazenar e disponibilizar notícias do G1, com endpoints para consulta, pesquisa por título e acesso individual às notícias.

	**Tecnologias:** Python, Flask, Selenium, SQL Server, pyodbc e REST API.

	### 2. Trending Movies
	**Resumo:** Aplicação web desenvolvida para exibir filmes e séries em alta, consumindo dados da API do TMDB e utilizando conceitos de desenvolvimento orientado por especificações (Spec-Driven Development).

	**Tecnologias:** React, JavaScript, API REST, TMDB e Vercel.

	### 3. Assistente de IA com Gemini
	**Resumo:** Aplicação de inteligência artificial capaz de responder perguntas com base em documentos institucionais, utilizando uma API de IA generativa para interpretar as solicitações dos usuários.

	**Tecnologias:** Python, FastAPI, Gemini API e processamento de documentos.

	### 4. InfraWatch — FIAP Global Solution
	**Resumo:** Projeto acadêmico voltado ao monitoramento de condições ambientais e análise de dados, combinando informações de sensores e dados orbitais para apoiar o acompanhamento de cenários de risco.

	**Tecnologias:** Python e processamento de dados.

	### 5. Automações RPA — MV3 Tecnologia
	**Resumo:** Desenvolvimento e sustentação de robôs para automatização de processos empresariais, envolvendo navegação web, extração e processamento de documentos, consultas a bancos de dados e integração entre sistemas.

	**Tecnologias:** Python, SQL Server, AutoMate Desktop, Power Automate Desktop, Selenium e PowerShell.
